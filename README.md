# smithos
Frontend using Typescript + Tailwinds + custom CSS to create an OS-like interface. Includes integrations to walletconnect, moralis, etherscan, etc.

# [agentsmith](https://github.com/Invention-foo/agentsmith_v1)
Using Agentstack and CrewAI to build an AI agent capable of analyzing users + their messages on X, determining whether they're a security risk (impersonator, malicious URL, false promotion, etc.).
